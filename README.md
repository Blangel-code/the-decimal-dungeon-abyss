## The Decimal Dungeon Abyss

# 📖 Acerca del Juego
The Decimal Dungeon Abyss es un proyecto indie desarrollado con enfoque en jugabilidad fluida y diseño adaptable para múltiples dispositivos. Explora mazmorras, derrota enemigos y supera desafíos adaptados tanto para teclado como para controles táctiles y mandos.

# ✨ Características Principales
Soporte Multiplataforma: Diseñado para ejecutarse en escritorio, dispositivos móviles y navegadores web (HTML5).

Controles Dinámicos: Sistema automático que detecta el tipo de entrada activa (Teclado/Mouse, Mando o Pantalla Táctil).

Interfaz Adaptativa: UI que escala y se reajusta dependiendo del dispositivo del jugador.

Estilo Gráfico: Arte Pixel Art 2D con renderizado optimizado mediante OpenGL3 (Compatibility).

# 🛠️ Tecnologías Utilizadas
Motor: Godot Engine 4.x (GDScript)

Renderizado: Compatibility Mode (WebGL2 / OpenGL3)

Plataforma Web: HTML5 exportado para Itch.io

# 🚀 Cómo Ejecutar el Proyecto Localmente
Clona este repositorio:

Bash
git clone https://github.com/Blangel-code/the-decimal-dungeon-abyss.git
Abre Godot Engine 4.

Haz clic en Importar y selecciona el archivo project.godot ubicado dentro de la carpeta clonada.

Presiona F5 para ejecutar e iniciar el proyecto.
